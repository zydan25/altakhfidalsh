# اكتمال واجهة الإدارة

RTL Mobile-First مع Drawer جانبي، حفظ حالة الأقسام، شريط تنقل سفلي للهاتف، PWA manifest وأيقونة وsafe-area وtouch targets.

الكتالوج: المنتجات، المسودات، التصنيفات الهرمية، العلامات التجارية، الألوان والمقاسات، المتغيرات، المخزون، الوسائط، الشارات والسياسات.
المنتج: Wizard متعدد الخطوات للبيانات والتصنيفات والوسائط والخيارات والمتغيرات والمخزون والسياسات والشارات والهاشتاجات والنشر.
الطلبات: snapshot للسعر وSKU وVariant والاختيارات وسجل الحالة والدفع والشحن والإرجاع والاسترداد والضمان والمحادثة.
العملاء: الحساب والعناوين والتسعير والطلبات والمحادثات والمحفظة والإشعارات.
Storefront: Pages وSections وItems ديناميكية.
الدفع والشحن: طرق ومعاملات وشحنات وtracking events.
النظام: الثيم والإعدادات وFeature Flags.
WhatsApp: Console لجلسة basheer مع status وQR وsend وmessages وerrors وnotifications وSocket.IO.
