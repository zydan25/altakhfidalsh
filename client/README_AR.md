# التخفيض الصح — تطبيق العميل

تطبيق Flutter مستقل بصريًا عن لوحة الإدارة ويستهلك نفس Flask API.

التشغيل:
  flutter pub get
  flutter run --dart-define=API_BASE_URL=https://takhfidsh.alattab.site/api/v1

الشاشات: تسجيل OTP، الرئيسية، الفئات، البحث، الجديد والعروض، تفاصيل المنتج، الترند والـLooks، المفضلة، السلة، Checkout، نجاح الطلب، الطلبات، تفاصيل الطلب، العناوين، الإشعارات، خدمة العملاء والحساب.
