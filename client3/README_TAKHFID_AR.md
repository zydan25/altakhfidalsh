# التخفيض الصح — التطبيق البديل (client3)

مجلد مستقل لتجهيز واجهة متجر بديلة مبنية على TStore وربطها بخادم Flask الحالي.

## الحالة
- `PLAN_AR.md`: خطة التنفيذ والاختبار.
- `API_MAPPING_AR.md`: خريطة API أولية، مع توضيح المسارات التي تحتاج تحققاً.
- وجود المصدر داخل المجلد لا يعني اكتمال الربط أو جاهزية النشر.
- README المصدر يعلن MIT، لكن ملف `LICENSE` لم يظهر في شجرة المصدر التي تمت مراجعتها. راجع `UPSTREAM_IMPORT_AR.md` والتحقق من الترخيص قبل النشر العام أو التوزيع التجاري.

## التشغيل
بعد تثبيت إصدار Flutter المناسب لقيود `pubspec.yaml`:

```bash
flutter pub get
flutter analyze
flutter test
flutter run --dart-define=API_BASE_URL=https://takhfidsh.alattab.site/api/v1
```

قد يتطلب المصدر إعداد `.env` محلياً. استخدم ملف المثال دون تضمين أسرار حقيقية في Git، ولا تضع مفاتيح Supabase أو أسرار الدفع داخل التطبيق.

## قواعد العمل
- جميع تعديلات التطبيق الثالث داخل `client3/`.
- لا تعدل `client/` أو `client2/`.
- لا تفعّل دفعاً حقيقياً قبل اعتماد تكامله واختباره.
